# Исправления по фотографиям Glassy V4

27 октября 2026. Эта ревизия уточняет предыдущую реализацию по реально приложенным фотографиям V4/V3 и скриншотам дефектов.

## Что исправлено

- **Регистрация и вход:** устранён конфликт общих стилей каталога с вложенными input. У поля одна рамка, прозрачный input, корректная ширина grid-колонок и видимый focus на обёртке. Пересобраны пропорции формы и автомобильной панели. Добавлены autocomplete, tel input, корректное имя password для screen reader. Успешная регистрация открывает личный кабинет.
- **Ошибки формы:** техническое `Validation failed` заменено понятными подсказками. Проверена обработка невалидного email. Минимум нового пароля в кабинете соответствует backend: 10 символов.
- **Хедер:** одинаковая геометрия controls, аккуратные графитовые основные кнопки, единые радиусы и иконка автомобиля для гаража. Устранено обрезание действий при 768 px. Убрано автоматическое скрытие хедера при прокрутке; ссылки доступны на закреплённой панели. Escape закрывает поиск/уведомления; записи уведомлений активируются с клавиатуры.
- **Лента категорий:** восстановлен непрерывный однонаправленный цикл из двух одинаковых групп. Перемещение на 50% даёт бесшовный стык. Есть рабочие пауза/продолжение; копии не дублируют keyboard navigation. При reduced motion доступна обычная прокручиваемая лента. Убраны растянутые полосы номеров и случайные асимметричные углы.
- **Dashboard:** новый фактурный световой фон, прозрачные поверхности, объёмные кромки, более плотная композиция, компактная верхняя навигация, графитовый Business Pulse и дополнительная диаграмма количества заказов из report.series. Демоданные подписаны; условная «прибыль 28%» убрана из интерфейса. Основные расчёты и API сохранены. Embedded-аналитика больше не создаёт вложенный main.
- **Кабинет:** самостоятельный React workspace: обзор, реальные счётчики заказов/гаража/избранного, последние заказы, бонусная карта, данные профиля, адреса доставки, уведомления и каналы, безопасность, история бонусов. Добавление/удаление адреса, основной адрес, профиль и настройки работают через существующий API. В мобильном кабинете доступен выход. Ошибки показываются пользователю.
- **Тестовая среда:** SSR-тесты используют отдельные каталоги кеша и выключенный WebSocket; запуск тестов не вмешивается в кеш запущенного frontend.

## Проверки

- `npm.cmd test`: **11 passed**, без прежнего сообщения о занятом WebSocket-порту.
- `npm.cmd run build`: TypeScript и Vite build проходят.
- Через браузер на **отдельной QA SQLite-базе**: регистрация → автоматический вход → кабинет; обновление имени; добавление основного адреса; изменение уведомлений, сохранение после reload; вход/выход; добавление в избранное и корзину; checkout с самовывозом и оплатой при получении; появление созданного тестового заказа в кабинете (1 заказ, 45 TJS, статус «Создан»). Тестовый заказ содержит `[DEMO ANALYTICS]` и не является реальной покупкой.
- Проверены размеры 320, 390, 768, 1440, 1920 px для регистрации, кабинета и dashboard. Во всех случаях **0 полей за границей родителя**, header actions находятся внутри viewport, документ не переполняется. Числовые результаты — `reference-v4/layout-checks.json`.
- Лента: вычисленные стили `42s`, `infinite`, `running`; координата transform меняется во времени. Кнопка паузы меняет состояние на `paused`, продолжение возвращает `running` даже при фокусе на кнопке.
- Финальная вкладка аналитики: Recharts отрисован, console errors отсутствуют. Светлая и тёмная темы проверены визуально.
